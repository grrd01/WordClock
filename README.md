# Word Clock

Als Onboarding-Projekt werden wir eine WordClock herstellen. Die Basis dazu kommt vom FabLab Bern:

https://fablab-bern.ch/wordclock-workshop/

### Wemos D1 mini - Microcontroller:
Das Herz unserer WordClock ist ein Wemos D1 mini. Dieser Arduino-kompatible Microcontroller läuft mit einem ESP8266 Chipsatz und wird mit der Arduino-IDE programmiert.

https://www.wemos.cc/en/latest/d1/d1_mini.html

### LED-Library:
Hinter jedem Buchstaben steckt eine programmierbare RGB-LED eines WS2812B LED-Strips. Diese werden über die Adafruip NeoPixel-Library angesteuert.

https://github.com/adafruit/Adafruit_NeoPixel

### GitLab-Repo zum forken:
Den Source-Code unserer Clock werden wir in einem Git-Repository auf GitLab führen. Jedes Team setzt einen Fork der Vorlage auf.

Vorlage: https://gitlab.com/u109281/word-clock

### Clockface-Generator:
Wer ein eigenes Zifferblatt erstellen will, kann dies mit Hilfe dieses Tools tun:

https://wordclock.collaud.me/
